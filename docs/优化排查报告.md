# Neo4j 服务优化指南：数据盘与内存配置

本文面向已部署 Neo4j 实例的用户，说明如何解决两个常见问题：
1. 挂载了数据盘，但 Neo4j 数据没有写入数据盘；
2. 大规格实例（如 16 核 64G）下，Neo4j 内存未针对机器做优化。

> 说明：以下操作均在实例的 ECS 上执行。请先通过服务实例详情页拿到公网/内网 IP，用实例密码 SSH 登录：`ssh root@<实例IP>`。操作前建议先对数据做备份。

> 验证情况：修复后的服务已使用 `ecs.u1-c1m4.4xlarge`（16 核 64 GiB）实例完成真实部署测试。ROS 栈和安装命令均执行成功；安装命令会校验数据盘已按 UUID 挂载到 `/data`，并在 Neo4j HTTP 服务就绪后才返回成功。内存环境变量也已通过真实 `neo4j:latest` 容器验证，31 GiB 堆能够被 JVM 正确读取和申请。

---

## 问题一：数据盘没用上，如何让数据落到数据盘

### 原因
实例虽然挂载了数据盘，但系统没有自动格式化和挂载它，同时 Neo4j 的数据目录默认指向系统盘（`/root/neo4j/data`）。因此数据盘一直空置，数据都写在 40G 系统盘上。

### 解决步骤

1. 登录实例后，查看磁盘，确认数据盘设备名（系统盘一般是 `vda`，数据盘通常是 `vdb`）：

   ```bash
   lsblk
   ```

2. 格式化数据盘并挂载到 `/data`，并写入 `/etc/fstab` 实现开机自动挂载（下面以 `/dev/vdb` 为例，请按上一步实际结果替换）：

   ```bash
   mkfs.ext4 /dev/vdb
   mkdir -p /data
   UUID=$(blkid -s UUID -o value /dev/vdb)
   echo "UUID=$UUID /data ext4 defaults,nofail 0 2" >> /etc/fstab
   mount -a
   df -h /data          # 确认 /data 已挂到数据盘
   ```

3. 把 Neo4j 数据迁移到数据盘，并修改 `docker-compose.yml` 让数据卷指向 `/data`：

   ```bash
   cd /usr/local/applications/
   docker compose down                       # 停止服务

   mkdir -p /data/neo4j/{data,logs,plugins,config}
   # 如系统盘已有数据，迁移过去（无历史数据可跳过）
   cp -a /root/neo4j/data/. /data/neo4j/data/ 2>/dev/null || true
   ```

   编辑 `docker-compose.yml`，把 `volumes` 改成指向 `/data`：

   ```yaml
       volumes:
         - /data/neo4j/logs:/logs
         - /data/neo4j/config:/config
         - /data/neo4j/data:/data
         - /data/neo4j/plugins:/plugins
   ```

4. 重启服务并验证数据盘已被使用：

   ```bash
   docker compose up -d
   du -sh /data/neo4j/data     # 数据盘上应能看到数据增长
   ```

## 问题二：如何按机器规格优化 Neo4j 内存

### 原因
默认部署没有配置 Neo4j 的堆内存（heap）和页缓存（pagecache），Neo4j 只能走内置默认值：堆最大约为物理内存的 25%（64G 机器约 16G），页缓存也偏小。大规格机器的内存被严重浪费。

### 推荐配置值

按机器内存计算（贴合 `neo4j-admin server memory-recommendation`）：

| 参数 | 计算规则 | 16 核 64G 推荐值 |
| --- | --- | --- |
| 堆内存 `heap`（initial 与 max 设成一致） | `min(31G, 内存/2)`（上限 31G，保留 JVM 指针压缩优势） | **31g** |
| 页缓存 `pagecache` | `(内存 - 堆) × 60%` | **19g** |

### 解决步骤

编辑 `/usr/local/applications/docker-compose.yml`，在 `environment` 下增加三行（以 16C64G 为例）：

```yaml
    environment:
      - NEO4J_AUTH_FILE=/run/secrets/neo4j_auth_file
      - NEO4J_server_memory_heap_initial__size=31g
      - NEO4J_server_memory_heap_max__size=31g
      - NEO4J_server_memory_pagecache_size=19g
```

保存后重启并确认参数生效：

```bash
cd /usr/local/applications/
docker compose up -d
docker exec -it $(docker compose ps -q neo4j) \
  bash -c "cat /var/lib/neo4j/conf/neo4j.conf | grep memory" 2>/dev/null || true
```

> 其它规格实例请按上表规则换算，例如 8 核 32G 建议 heap 约 16g、pagecache 约 9g。

## 一次性完成（可选）

若希望上述两步一起处理，可在实例上直接执行下面脚本（自动挂盘 + 按内存计算参数 + 重写并重启）：

```bash
#!/bin/bash
set -e
cd /usr/local/applications/

# 1) 挂载数据盘
DATA_DIR=/data
DATA_DISK=""
for dev in /dev/vdb /dev/vdc /dev/nvme1n1; do
  if [ -b "$dev" ] && [ -z "$(lsblk -no MOUNTPOINT $dev)" ]; then DATA_DISK="$dev"; break; fi
done
if [ -n "$DATA_DISK" ]; then
  blkid "$DATA_DISK" >/dev/null 2>&1 || mkfs.ext4 -F "$DATA_DISK"
  mkdir -p "$DATA_DIR"
  UUID="$(blkid -s UUID -o value $DATA_DISK)"
  grep -q "$UUID" /etc/fstab || echo "UUID=$UUID $DATA_DIR ext4 defaults,nofail 0 2" >> /etc/fstab
  mount -a
fi
mkdir -p $DATA_DIR/neo4j/data $DATA_DIR/neo4j/logs $DATA_DIR/neo4j/plugins $DATA_DIR/neo4j/config
cp -a /root/neo4j/data/. $DATA_DIR/neo4j/data/ 2>/dev/null || true

# 2) 按内存计算堆与页缓存
MEM_GB=$(awk '/MemTotal/{printf "%d", $2/1024/1024}' /proc/meminfo)
HEAP=$((MEM_GB/2)); [ $HEAP -gt 31 ] && HEAP=31; [ $HEAP -lt 1 ] && HEAP=1
PAGECACHE=$(( (MEM_GB-HEAP)*3/5 )); [ $PAGECACHE -lt 1 ] && PAGECACHE=1

# 3) 重写 docker-compose 并重启
docker compose down || true
cat > ./docker-compose.yml <<COMPOSE
services:
  neo4j:
    image: neo4j:latest
    volumes:
      - $DATA_DIR/neo4j/logs:/logs
      - $DATA_DIR/neo4j/config:/config
      - $DATA_DIR/neo4j/data:/data
      - $DATA_DIR/neo4j/plugins:/plugins
    environment:
      - NEO4J_AUTH_FILE=/run/secrets/neo4j_auth_file
      - NEO4J_server_memory_heap_initial__size=${HEAP}g
      - NEO4J_server_memory_heap_max__size=${HEAP}g
      - NEO4J_server_memory_pagecache_size=${PAGECACHE}g
    ports:
      - "7474:7474"
      - "7687:7687"
    restart: always
    secrets:
      - neo4j_auth_file
secrets:
  neo4j_auth_file:
    file: ./neo4j_auth.txt
COMPOSE
docker compose up -d
echo "完成：数据盘挂载到 $DATA_DIR，heap=${HEAP}g pagecache=${PAGECACHE}g"
```
